Ievan Polkka PV mod - Hatsune Miku: Project DIVA (PSP)
=======================================================

On the PSP, "Ievan Polkka" only had a slideshow of illustrations. This mod gives it a full 3D PV:

  - Miku dancing the Project DIVA Ievan Polkka choreography, in sync with the song
  - the PV camera work (cuts, close-ups, zoom shots)
  - a bright grass-field stage (sky, clouds, hills, grass, flowers)
  - leeks in her hands during the leek sections
  - lip sync while she sings
  - Ievan Polkka unlocked from the start on a new save

The rhythm game keeps the original PSP Easy / Normal / Hard note charts.


WHAT YOU NEED
-------------
Your own copy of the game as an ISO:

    Hatsune Miku: Project DIVA (Japan, ULJM-05472) with the English patch v1.0 applied

The installer checks your ISO and refuses anything else (other versions, untranslated ISOs, or an
ISO that is already modded), so it can't produce a broken file.
This mod does NOT include the game. You must use your own copy.


HOW TO INSTALL
--------------
1. Double-click IevanPolkkaPatcher.exe   (Windows 10/11; nothing else to install)
   If Windows says "Windows protected your PC", click "More info" and then "Run anyway".
   The warning appears because the program isn't signed.
2. Click "Browse..." and pick your game ISO.
3. Check where the modded ISO will be saved (by default: next to yours, named "... (Ievan Polkka mod).iso").
4. Click "Install mod". It takes a few seconds to a minute.

Your original ISO is never changed. You get a second, modded ISO (about 1.7 GB).

Command line (optional):
    IevanPolkkaPatcher.exe "C:\path\to\your.iso" ["C:\path\to\output.iso"]


HOW TO PLAY
-----------
- Tested in PPSSPP. It should also work on a real PSP with custom firmware (not tested yet).
- Start a NEW game (an existing save keeps its own unlocks).
- Go to Free Play and pick "Ievan Polkka".


NOTES
-----
- PV Mode (watching without notes) follows the game's normal unlock rules for now.
- The mod only changes Ievan Polkka's files. Every other song is left as it was.
- If the installer says your ISO isn't supported, it's a different dump or version of the game.
  Make sure it's the Japanese ULJM-05472 release with only the English patch v1.0 on it.
